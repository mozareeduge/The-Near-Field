`ENTRY → FIELD → SELECTION → MOVEMENT → LITERARY EVENT → MAP⇄PROSE → AGAIN/RETURN`

## D. Accessibility/responsive

Exercise, do not only inspect:

- keyboard-only complete path;
- 390×844 and wide desktop;
- 200% zoom;
- reduced motion;
- visible focus;
- mobile tap bindings;
- non-color route-state distinction;
- textual selected-place/movement summary outside map canvas;
- no critical action blocked by virtual keyboard/viewport.

## E. Privacy/security/resilience/cost

Close applicable matrix cases, especially:

- exact GPS absent from model payload and analytics;
- no frontend secrets;
- source/model strings rendered as text, not trusted HTML;
- malicious source prompt remains data;
- stale request cancellation;
- provider errors preserve valid prior state;
- bounded retries/candidates/words/model calls;
- rate limiting/CSP/secrets where deployed;
- telemetry records versions/tokens/latency without raw GPS;
- normal run uses exactly two model roles.
