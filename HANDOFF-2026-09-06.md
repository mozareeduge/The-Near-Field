## 4. 9router activation (turn the live site onto muse-spark for the test phase)

Production defaults to OpenRouter and works with zero dependency on your
machine. 9router is opt-in: while your tunnel is up the live site uses
muse-spark (free tokens); when it is down the provider chain falls straight
back to OpenRouter — nothing breaks.

Steps (need your Windows machine with 9router already running on `localhost:20128`):

1. From the repo root: `node scripts/expose-9router.mjs`
   It prints a public `https://<sub>.loca.lt` URL and keeps running
   (auto-reconnects). Leave that terminal open for the whole test session.
2. Add two **repository** secrets at
   `github.com/mozareeduge/The-Near-Field/settings/secrets/actions`:
   - `NINEROUTER_BASE_URL` = the `https://<sub>.loca.lt` URL from step 1
   - `NINEROUTER_API_KEY`  = your 9router key
     (the same value as `HERMES_CUSTOM_9ROUTER_API_KEY` in
     `%LOCALAPPDATA%/hermes/.env`)
3. Re-deploy the worker: Actions tab → "Deploy worker to Cloudflare" → Run
   workflow (on `main`). Or from a shell: `gh workflow run deploy-worker.yml`.
4. Verify: run a search on the live site; a gather/synthesize response's
   `meta.provider` should read `ninerouter`. If the tunnel is down it reads
   `openrouter` — that is the safety net working, not a failure.

To go back to OpenRouter-only: stop the tunnel process, or delete the two
secrets and re-deploy.

**Standing rule:** worker deploys are path-filtered to `apps/worker/**`;
web-only commits need `gh workflow run deploy-worker.yml` run manually.

**Pre-existing platform gaps (unchanged, optional):** ORS_API_KEY /
MAPTILER_API_KEY absent (fallbacks honest and tested); Nominatim caching
(1h TTL) considered for autocomplete; the `Workers Builds: the-near-field`
Cloudflare check is a misconfigured Git integration (service name mismatch,

### Tunnel notes
- `cloudflared` quick tunnel is **impossible on this network** (Cloudflare
  edge DNS `region1.v2.argotunnel.com` SRV is ISP-filtered). Serveo resolves
  to RFC1918. Do not re-try either.
- `scripts/expose-9router.mjs` uses `localtunnel` (no account). For a permanent
  setup instead: ngrok with an authtoken, or run 9router on a cheap VPS and
  point `NINEROUTER_BASE_URL` at that.
