## 3. Repo tools added this round

- `scripts/dev-live-server.mjs` — local dev live server. Runs the worker
  in-process on **8789** and forwards to 9router at localhost:20128. Usage:
  ```
  node --experimental-strip-types scripts/dev-live-server.mjs   # wait for LIVE-READY 8789
  # separate shell, repo root:
  VITE_API_BASE=http://localhost:8789 npm run dev:web           # vite on 5173
  ```
  Requires 9router running on 20128 and the API key (env `NINEROUTER_API_KEY`,
  or `%LOCALAPPDATA%/hermes/.env` `HERMES_CUSTOM_9ROUTER_API_KEY`).
  Set `NF_DEBUG_CAPTURE=1` to dump LLM request/response bodies to
  `%TEMP%/nf_live_*.txt`. **Gotchas (already encoded, do not undo):** bind all
  interfaces (Chrome resolves localhost→::1 first), forward all request headers
  (CORS needs Origin) and all response headers (else every browser call fails).

   Assessed exhaustively on 2026-09-06 (do NOT re-try these):
